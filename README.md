# LeetCode Daily Solutions

Daily solutions to LeetCode problems. My primary language is **Elixir**, but
when a problem doesn't support it, I use **C++**.

## File Structure

```
q1/
├── elixir/
│   └── solution.exs
├── cpp/
|   └── solution.cpp
q2/
├── elixir/
|   └── solution.exs
q3/
└── cpp/
    └── solution.cpp
```

Each problem resides in a directory named `q[question_number]`. Within each,
language-specific directories contain the solution file.

## Progress

Solutions are uploaded daily.
